## 📂 Annotation Projects

### Sentiment Classification – Product Reviews
**Description:**  
Annotated customer product reviews from a retail store into sentiment categories (e.g., Positive, Neutral, Negative, Uncertain). The project emphasizes consistency in subjective language interpretation and edge-case handling (sarcasm, mixed sentiment).

**Use Case:**  
- Customer feedback analysis  
- Product quality monitoring  
- Review-based recommendation systems  

🔗 **Project Link:** [Sentiment Classification Project](./Sentiment%20Classification/)

### ATIS Semantic Annotation
**Description:**  
Semantic annotation of the ATIS (Airline Travel Information System) dataset, including **intent classification** and **slot labeling**. This project follows standard NLP conventions used in spoken language understanding (SLU) systems.

**Use Case:**  
- Virtual assistants  
- Conversational AI  
- Intent detection models  

🔗 **Project Link:** [ATIS Semantic Annotation Project](./ATIS%20Semantic%20Annotation/)

**Use Case:**

- Text parsing pipelines  
- Language understanding tasks
